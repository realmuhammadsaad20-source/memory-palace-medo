# How to Build and Install the APK 📱

Follow these simple steps to obtain your APK:

1. Extract this zip archive.
2. Create a new repository on [GitHub](https://github.com).
3. Upload all files (including the `.github` folder) to your repository.
4. Go to the **Actions** tab on GitHub.
5. GitHub will automatically run the `Build Release APK` workflow.
6. Once finished (3-5 minutes), download `Memory-Palace-Medo-APK` from the **Artifacts** section at the bottom.
7. Transfer to your Android phone and install!
