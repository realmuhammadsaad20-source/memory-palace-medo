# ميموري بالاس ميدو (Memory Palace Medo) 🏰🎥

تطبيق متكامل لتقنية **قصر الذاكرة التفاعلي بالفيديو (Video-based Memory Palace)** لهواتف أندرويد.

---

## 🌟 الميزات وحلول المشاكل التقنية في هذا الإصدار:

1. **تعدد الفيديوهات والقصور:** إمكانية إنشاء عدد لا نهائي من القصور، وتسمية كل قصر وربطه بفيديو مستقل من الاستوديو.
2. **حل مشكلة الشاشة السوداء نهائياً:** مشغل فيديو مخصص متوافق مع دورة حياة أندرويد مع تهيئة آمنة لمنع أي تجمد أو وميض أسود.
3. **دقة وضع المحطات:** نظام الإحداثيات النسبية الموحدة ($X\% / Y\%$) لضمان بقاء النقطة في مكانها الصحيح مهما اختلف حجم شاشة الهاتف أو اتجاه العرض.
4. **نسخ الفيديوهات محلياً:** حماية الفيديوهات داخل ذاكرة التطبيق الخاصة حتى لا تضيع المحطات إذا حُذف الفيديو من ألبوم الهاتف.
5. **وضع الاستذكار والاختبار (Active Recall):** توقف تلقائي للفيديو عند كل محطة، واختبار ذاكرتك قبل كشف المعلومة.

---

## 🚀 كيف تحصل على ملف الـ APK وتثبته على هاتفك (بدون أي خبرة برمجية)؟

المشروع مزود بخاصية **البناء السحابي التلقائي (GitHub Actions)**؛ خوادم GitHub ستقوم ببناء الـ APK نيابة عنك مجاناً عبر الخطوات التالية:

### الخطوة 1: إنشاء مستودع (Repository) على GitHub
1. ادخل إلى موقع [GitHub.com](https://github.com) وسجل حساباً مجانياً إذا لم يكن لديك حساب.
2. اضغط على علامة **(+)** أعلى الصفحة ثم اختر **New repository**.
3. اكتب اسماً للمستودع (مثلاً: `memory-palace-medo`)، واجعله عاماً (Public) أو خاصاً (Private)، ثم اضغط **Create repository**.

### الخطوة 2: رفع ملفات المشروع
1. في صفحة المستودع الجديد، اضغط على **uploading an existing file**.
2. اسحب ملفات هذا المجلد وأفلتها في المتصفح.
3. انزل لأسفل واضغط **Commit changes**.

### الخطوة 3: استلام ملف الـ APK الجاهز!
1. اضغط على تبويب **Actions** في أعلى صفحة المستودع على GitHub.
2. ستجد عملية بناء تعمل تلقائياً اسمها: **Build Release APK**.
3. انتظر حوالي 3 إلى 4 دقائق حتى تكتمل وتظهر علامة صح خضراء (✔️).
4. اضغط على اسم العملية، وانزل إلى قسم **Artifacts** في الأسفل.
5. ستجد ملفاً باسم: **Memory-Palace-Medo-APK**، اضغط عليه لتحميله.
6. افتح الملف على هاتفك وثبّت التطبيق فوراً واستمتع بقصر الذاكرة الخاص بك!
