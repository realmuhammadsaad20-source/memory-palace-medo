# ميموري بالاس ميدو (Memory Palace Medo)

تطبيق قصر الذاكرة التفاعلي بالفيديو على أندرويد مبني بـ Flutter.

## المميزات
- دعم عدد غير محدود من القصور والفيديوهات.
- حفظ الفيديوهات داخل مساحة التخزين الداخلية للتطبيق.
- نظام إحداثيات نسبية (X%, Y%) لضمان دقة مواضع المحطات عبر الشاشات المختلفة.
- وضع استذكار نشط مع توقف تلقائي عند كل محطة وزر لكشف المحتوى.

## البناء التلقائي لـ APK عبر GitHub Actions
المستودع مجهز بـ Workflow في `.github/workflows/build-apk.yml`.
1. اذهب إلى تبويب **Actions**.
2. اختر آخر عملية تشغيل ناجحة.
3. حمّل الـ APK من قسم **Artifacts** باسم `Memory-Palace-Medo-APK`.
